# migrations_archive

Архів міграцій, що не застосовуються в поточному контурі.

**Що тут:** legislation-міграції (validity_status, RLS, legislation_documents_ui, import jobs/proposals тощо), перенесені з `migrations/` для історії. Не запускати як частину `supabase db push` / migrate.

**Коли використовувати:** лише для довідки або ручного застосування в окремому середовищі.
