## Примітки

**Ручний аудит виконується вручну через Supabase UI або SQL запити.**

Для кожного документа потрібно перевірити:
1. **title/summary відповідає document_type_slug** - чи логічно тип документа відповідає змісту
2. **category логічно відповідає змісту** - чи правильно визначена категорія права
3. **chunks співпадають** - expected_chunks = indexed_chunks
4. **health badge коректний** - чи правильно визначений sync_health

**Особлива увага:**
- n0002525-26 має health=red - потребує перевірки причини
- Документи з health=null - нові, ще не пройшли verify --write-health
