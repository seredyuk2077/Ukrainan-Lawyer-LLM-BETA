# Deprecated: Cloudflare Vectorize (DocListDB catalog)

Цей підкаталог містить **legacy/архівні** матеріали, які стосувались **Cloudflare Vectorize**.

**Стан на 2026‑01‑21:** у проді DocListDB каталог актів працює на **Qdrant**, а **Cloudflare Vectorize не використовується**.

## Що тут лежить

- `createIndex.ts` — історичний скрипт створення Vectorize індексу `legislation-catalog-index`.
- `VECTORIZE_CATALOG_DB.md` — стара документація контракту Vectorize індексу.

## Чому збережено

- Для історії/контексту (як було організовано на ранніх етапах).
- Щоб не змішувати “актуальний прод” з legacy інфрою.

## Актуальний прод (куди дивитись замість цього)

- `scripts/legislation/Documentation List DB/README.md`
- `scripts/legislation/Documentation List DB/ARCHITECTURE.md` (основний entrypoint архітектури)
