## ✅ Виправлені помилки

### 1. `law_number` не витягувався
**Проблема:** Поле `law_number` було `null` для всіх документів  
**Виправлення:** Додано логіку витягування `law_number` з назви документа та поля `orgnum` в `buildCanonical.ts`

### 2. `datredRaw` синтаксична помилка
**Проблема:** Рядок 146 мав неповний код: `const datredRaw =  || jsonData?.metadata?.datred;`  
**Виправлення:** Виправлено на: `const datredRaw = jsonData?.datred || jsonData?.meta?.datred || jsonData?.metadata?.datred;`

### 3. `guessDocumentType` не використовував JSON `typ`
**Проблема:** Тип документа визначався тільки з назви, не враховуючи `typ` з JSON  
**Виправлення:** 
- Додано перевірку `typ` з JSON (typ=1=Закон, typ=2=Постанова, typ=21=Кодекс, typ=216=Конституція)
- Додано визначення "Постанова КМУ" через `organs` (орган=2 = КМУ)
- Додано підтримку typ=21 для Кодексу
