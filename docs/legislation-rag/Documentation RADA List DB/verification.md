## 2. Delta endpoint — `/laws/main/r.json`

### URL та доступність

**URL:** `https://data.rada.gov.ua/laws/main/r.json`

**HTTP Headers (без User-Agent):**
```
HTTP/1.1 200 OK
Server: nginx/1.19.0
Content-Type: application/json; charset=utf-8
```

**HTTP Headers (з User-Agent: OpenData):**
```
HTTP/1.1 403 Forbidden
```

**Статус:** ✅ Доступний, але **НЕ з User-Agent: OpenData**

**Примітка:** Endpoint працює з дефолтним User-Agent (curl) або без явного вказання. З `User-Agent: OpenData` повертає 403 Forbidden.

### Структура JSON

**Тип відповіді:** `dict` (об'єкт, не масив)

**Структура:**
```json
{
  "cnt": 682,        // Загальна кількість оновлених документів
  "from": 1,         // Початок пагінації
  "list": [...],     // Масив документів (50 елементів за раз)
  "max": 50          // Максимум елементів на сторінку
}
```

**Поля документу в `list`:**
```json
{
  "dokid": 551250,
  "nreg": "n0020500-26",
  "nazva": "Про облікову ціну банківських металів",
  "status": 0,
  "types": 95,
  "organs": "70:20260114:",
  "orgid": 70,
  "minjust": "",
  "orgdat": 20260114,
  "poddat": 20260114,
  "pridat": 20260114,
  "typ": 95,
  "num": 1,
  "npix": 2,
  "n_vlas": "",
  "orgnum": null
}
```

**Пагінація:** Так, повертає 50 елементів за раз. Для отримання всіх потрібно використовувати параметри `from` та `max`.

### Висновок для `/laws/main/r.json`

✅ **Endpoint працює, але:**
- ❌ **НЕ працює з `User-Agent: OpenData`** (403 Forbidden)
- ✅ Працює без User-Agent або з дефолтним curl User-Agent
- ✅ Повертає валідний JSON
- ✅ Містить поля для ідентифікації: `nreg`, `dokid`, `datred` (через `orgdat`/`poddat`/`pridat`)
- ⚠️ **Пагінація:** Потрібно робити кілька запитів для отримання всіх оновлених документів

**Рекомендація:** 
- Використовувати дефолтний User-Agent або не вказувати User-Agent явно
- Обробляти пагінацію (параметри `from` та `max`)
- Для delta updates: порівнювати `datred` з поточним станом в БД
